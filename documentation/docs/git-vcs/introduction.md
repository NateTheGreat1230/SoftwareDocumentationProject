# Introduction to Version Controls (Git)

A Version Control System (VCS) is a software tool that helps developers track and manage changes to code over time. 

Instead of saving countless copies of a project file like "code-v1.js", "code-v2-final.js", "code-v2-final-really.js", a VCS efficiently records every modification made to the project's files and directories.

## Why is VCS Useful?
1. Rollbacks: You can revert files or the entire project back to any previous state. This is essential for fixing bugs or undoing mistakes.

2. Collaboration: Multiple developers can work on the same project simultaneously without overwriting each other's changes.

3. Branching: Developers can create independent lines of development (branches) to test new features or fixes without affecting the stable main codebase.

4. History and Accountability: Every change is recorded with who made it, when, and why, providing a clear audit trail.

## How do I get started?

By using VSCode, you will be able to interact with an interface that makes the version control process much easier! The most popular version control system that is in use today is ```Git```, and it is used for the development of almost all of the software coming out today.

Learning how to use Git will make you a much better programmer to work with, and it will also save you from countless headaches. Before you get started with using git in VS Code, make sure to familiarize yourself with git!
