# Documentation Overview and Introduction

Welcome to our VS Code documentation. We strive to provide thorough and intuitive step by step instructions to complete many tasks in VS Code. VS Code is an open source code editor provided by Microsoft supporting nearly every major programming language with a fully customizable user interface and setup to optimize your workflow to your preferences. VS Code integrates Artificial Intelligence (AI) to assist you in your code writing experience. Whether connected remotely or through the cloud, VS Code is one of the most widely used text-based code editors by developers of all sorts across the world.

### Audience Analysis

The intended audience for this documentation are newer developers who are seeking a base understanding of VS Code and have trouble reading the main documentation provided by Microsoft. This audience is appropriate for the assignment because it is a wide audience that will be best served by the style undertaken. Our strategies were to reduce technical jargon that's found in the main documentation and to keep the language simple and easy to understand with plenty of help to show users how to make VS Code work for them. One instance of this is in the [Windows installation instructions](installation-instructions/windows.md) where we not only say "Run the installer" but add "This should be in a file called `VSCodeUserSetup-{versionNumber}.exe` and will be in your downloads folder."

### Content Analysis

The research we conducted included seeing which features we took most advantage of in our own use of VS Code and others that would be helpful to people learning to use VS Code. We included the information we did because we figured it would be the most necessary to help our audience. There are many different parts of VS Code that we did not address because it is a very configurable and very large piece of software made for and by engineers who are known for their eccentricity in setup.


### Appearance Analysis

The format choices we made were to keep our documentation simple, clean, and focused. A new audience being exposed to hundreds of features at once is going to be overwhelemed, so we ensured our format and design were clear and slow to introduce new content at a rate they would be most comfortable with. One way this is introduced is in the [extensions](category/extensions) where we break down the two different sources of extensions onto separate pages rather than overwhelming the user with both options being present on the screen at once.

### Ethics Analysis

We felt the ethical responsibility to make sure our language was different than VS Code's original documentation. We intended to see what we could do better to help the user given that the intended audience isn't familiar with a lot of technical jargon. We chose to avoid direct quotation because not only would it be plagiarism and illegal, but it would be a disservice to those who we aim to help with our documentation to use the very language they're not familiar with. For instance, the [Copilot Chat](copilot/copilotChat.md) breaks down the complexity of the different chat modes into smaller and more digestible pieces of information. Agent Mode is described lightly as "optimized for complex coding tasks" compared to VS Code's description including not only the aforementioned information but adding that Agent Mode is "based on high-level requirements that might require running terminal commands and tools."

### Experience Analysis

Next time we write this documentation, perhaps we will be more focused in which tools we choose to highlight and how we introduce them. Our documentation is very "go at your own pace" in its tone and style. We enjoyed using Markdown to write this and the software we used to do it was fun to learn and use, but it was difficult to ensure that everyone was involved because it's not a singular collaborative document but rather a collection of files displayed.

## General Warnings

This documentation is not all inclusive of all the features available in VS Code for users. It is a base to start for those who have trouble understanding the main VS Code documentation and provides basic instructions on customization and access to features. Ensure that your system meets the requirements specified in the installation instructions and that you know your own systems limits for any code you intend to write. Be careful of any third-party software including packages, extensions, chat models, or any other tool that could potentially introduce malware onto your device.
