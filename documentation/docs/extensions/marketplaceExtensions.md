# Using Visual Studio Marketplace

Visual Studio Marketplace is a place made by Microsoft for accessing additional features for Visual Studio. We will focus on the extensions menu, but many other features are available.

## Installing a VS Code Extension from Visual Studio Marketplace
You can install an extension from the Visual Studio Marketplace by doing the following:
1. Go to [marketplace.visualstudio.com/vscode](https://marketplace.visualstudio.com/vscode).
![Visual Studio Marketplace Home Page](/img/copilot-extensions/marketplaceMenu.png)
1. Search for the extension you wish to install using the search bar and/or scrolling down on the webpage.
1. When you find the extension you wish to install, select it. You should be directed to a new page.
1. On the new page, click the green **Install** button.
![Visual Studio Marketplace Install Button](/img/copilot-extensions/marketplaceInstall.png)

## Uninstalling or Disabling a VS Code Extension

To uninstall or disable a VS Code Extension, you need to go to the Extensions View. More instructions can be found [here](/docs/extensions/installExtensions#uninstalling-or-disabling-a-vs-code-extension).
